"onProjectileHitBlock" - 方块被弹射物击中
监听函数原型 function(block,source)
参数：
block : Block
被击中的方块对象
source : Entity
发射的弹射物实体（如箭）
拦截事件：不可以拦截

"onDispenseItem" - 发射器/投掷器发射普通物品
监听函数原型 function(pos,item,slot,face,container)
参数：
pos : FloatPos 发射物品出现的位置
item : Item 被发射的物品对象
slot : Integer 容器中被取出物品的槽位索引
face : Integer 发射时方块朝向数值
container : Container 发射器/投掷器的容器对象
拦截事件：函数返回false
